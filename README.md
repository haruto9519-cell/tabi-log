# 旅ログ（Tabi Log）

Aileronで作成した旅行プランを引き継ぎ、訪問先・日記・支出を旅行ごとに整理する個人向け旅行記録サービスです。

## 公開URL

- Webアプリ: https://tabi-log.pages.dev/
- Worker health: https://tabi-log.haruto-9519.workers.dev/api/health

## 現在の機能

- スマートフォン対応の旅行記録UI
- Googleログインと7日間のアプリセッション
- Aileronから旅行プランを一時トークンで取り込む機能
- 旅行・日別の予定・訪問済み状態の管理
- 日記の追加・編集・削除、旅行・訪問先との紐づけ
- 写真（JPEG・PNG・WebP、1枚5MBまで）の端末内保存
- 旅行ごとの予算・支出の記録と集計
- 旅行の共有URL発行・閲覧・無効化
- 共有用PNGカードとSNS投稿文の作成

## 保存先と同期の範囲

| データ | 現在の保存先 | 注意点 |
|---|---|---|
| 旅行・日程・日記の文章 | ブラウザ内 + ログイン時のCloudflare D1同期 | 同期の本番動作はアカウントごとに確認が必要 |
| 予算・支出 | ブラウザ内 + ログイン時のCloudflare D1同期 | 通貨が異なる支出は合算しません |
| 写真 | ブラウザのIndexedDB | 端末内のみ。別端末には同期されません |
| 共有リンクの内容 | Cloudflare D1 | 共有リンクを知っている人は閲覧できます |
| いいね・コメント・フォロー等 | 一部ブラウザ内のデモ状態 | 利用者間で同期するSNS機能ではありません |

**写真のGoogle Drive保存・別端末同期は、現時点では未実装です。** Google Drive連携が利用できるように見える説明が残っている場合でも、写真は端末内保存として扱ってください。ブラウザの閲覧データを消去すると、端末内の写真が失われる場合があります。

## 共有機能の制限

- 共有URLを発行した場合に限り、選択した旅行名、エリア、説明、訪問先、日記テキスト等が共有されます。
- 共有URLは原則として発行から365日で期限切れになります。
- 共有URLを知っている人は内容を閲覧できます。個人情報や現在地などを含めないでください。
- 共有ページには写真本体は含まれません。
- 共有URLの発行APIには、本文サイズ上限とIPハッシュ単位の回数制限があります。

## 技術構成

- Frontend: Cloudflare Pages（`tabi-log.pages.dev`）
- API: Cloudflare Workers（`tabi-log.haruto-9519.workers.dev`）
- Database: Cloudflare D1（`tabi-log-db`）
- 地図表示: Leaflet / OpenStreetMap
- 認証: Google Identity Services + Worker側IDトークン検証

## 公開前・継続開発で必要な確認

1. Googleログイン、ログアウト、セッション期限切れの実機確認
2. 旅行・日程・日記・支出の保存、再読み込み、再ログイン後の復元確認
3. 別アカウントから他人の非公開データを取得・変更できないことの確認
4. 写真の端末内保存・差し替え・削除の確認と、クラウド写真保存方式の検討
5. 共有URLの発行・閲覧・無効化と、共有対象データの確認
6. スマートフォンでの表示、入力、アクセシビリティの確認
7. データのエクスポート・アカウント削除手順の整備
8. SNS向けデモUIと実際に利用できる機能の表示を整理

「画面にボタンがある」だけでは完成とせず、保存・再読み込み・再ログイン・権限・エラー時の動作まで確認できた機能だけを完了扱いにします。
