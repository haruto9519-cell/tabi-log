# 旅ログ First Test Version 1.0

Aileronとは独立した旅の記録・共有サービスの第一テスト版です。

## 公開方法
Cloudflare Pagesでこのリポジトリを接続し、ビルドコマンドは空欄、出力先ディレクトリは `/`（または `.`）にしてデプロイします。ルートの `index.html` がトップページです。

## ブラウザ内で試せる機能
- モバイル対応UI
- 旅程作成・削除・コピー、立ち寄り先追加
- ルートプレビュー（実地図ではない）
- 実際に訪れた場所の記録
- 写真/動画投稿（5MBまで、端末内保存）
- 投稿を旅程に紐づける、日記タイムライン
- フィード検索・カテゴリ絞り込み・新着/人気順
- いいね・コメント・保存・フォローUI
- 投稿を参考にした旅程コピー
- 公開範囲UI、通報UI、プライバシー説明
- DMなし

## 重要な制限
これは同じブラウザ内で操作を試す第一テスト版です。ログイン、ユーザー間データ共有、サーバー保存、実地図/GPS、フォロー機能の実通信、通報の運営受信、動画ストリーミングは未接続です。表示される初期投稿はサンプルです。「公開」に設定した投稿も現時点では他の利用者には公開されません。投稿・旅程・プロフィール等はlocalStorage、写真/動画はIndexedDBに保存されます。

## Cloudflareバックエンド準備ファイル
- `worker/src/index.js`: 認証が設定されない限り書き込みを拒否するAPI骨格
- `worker/migrations/0001_init.sql`: D1スキーマ
- `worker/wrangler.toml`: D1バインディング設定例（database_idは未設定）

本番化前に認証、D1、R2メディア保存、投稿権限、ユーザー間アクセス制御、通報運営フロー、利用規約/プライバシーポリシーを実装・検証してください。Aileron連携は別途認証・データ形式確定後に接続します。
