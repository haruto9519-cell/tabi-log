# 旅ログ（Tabi Log）

Aileronで作成した旅行プランを引き継ぎ、訪問先・日記・支出を旅行ごとに整理する個人向け旅行記録サービスです。

## 公開URL

- Webアプリ: https://tabi-log.pages.dev/
- Worker health: https://tabi-log.haruto-9519.workers.dev/api/health

## 現在の機能

- スマートフォン対応の旅行記録UI
- Googleログインと7日間のアプリセッション
- Googleログイン中の旅ログアカウント削除（クラウドデータ・セッション・当該端末のアカウント別データ）
- Aileronから旅行プランを一時トークンで取り込む機能
- 旅行一覧の検索・日付／名前順の並び替え・アーカイブ管理・複製
- 日別の予定・訪問済み状態の管理と手動順序変更
- 地図上の訪問先ピン表示と、同意した場合の車・徒歩ルート検索
- 日記の追加・編集・削除、旅行・訪問先との紐づけ
- 写真（JPEG・PNG・WebP、1枚5MBまで）の端末内保存と非公開クラウド同期
- 動画（MP4・WebM・MOV、1本20MBまで）の端末内保存・再生
- 写真の非公開クラウド同期（Googleログイン時、Cloudflare D1。別端末での同一アカウント表示に対応するコードを実装）
- クラウド保存用写真のWebP圧縮（1枚あたり最大1.35MB）
- 写真のJSONバックアップ・復元（端末内写真データを含む。欠損写真・90MB超の不完全なバックアップを防止）
- 旅行ごとの予算・支出の記録と集計
- 旅行の共有URL発行・閲覧・無効化
- 共有用PNGカードとSNS投稿文の作成
- 旅行・日記・支出・プロフィール・端末内写真のJSONバックアップ保存と、この端末への復元（復元前の形式検査と失敗時のロールバック）

## 保存先と同期の範囲

| データ | 現在の保存先 | 注意点 |
|---|---|---|
| 旅行・日程・日記の文章 | ブラウザ内 + ログイン時のCloudflare D1同期 | 同期の本番動作はアカウントごとに確認が必要 |
| 予算・支出 | ブラウザ内 + ログイン時のCloudflare D1同期 | 通貨が異なる支出は合算しません |
| 写真 | ブラウザのIndexedDB + ログイン時のCloudflare D1（非公開コピー） | クラウド同期は実装・本番反映済み。別端末での実機受け入れ確認は未完了 |
| 動画 | ブラウザのIndexedDB | 1本20MBまで。クラウド同期・共有は未対応。JSONバックアップで手動移行 |
| 共有リンクの内容 | Cloudflare D1 | 共有リンクを知っている人は閲覧できます |
| いいね・コメント・フォロー等 | 一部ブラウザ内のデモ状態 | 利用者間で同期するSNS機能ではありません |

写真は端末内のIndexedDBに保存し、ログイン・同期後に非公開のクラウドコピーをアップロードします。クラウド側では大きな写真をWebPに圧縮し、1枚1.35MB以下に制限します。保存上限は1ユーザー80MB、アプリ全体400MBです。端末内の写真はクラウド保存に失敗しても保持されます。クラウド同期のコードとWorker本番デプロイは完了していますが、同一Googleアカウントでの別端末表示は実機確認が必要です。

バックアップはマイページからJSONファイルとして保存できます。端末内の写真・動画も含めます。写真が欠けている場合は不完全なバックアップを防ぐため保存を中止し、ファイルサイズは90MB以下に制限します。復元は現在の端末データを置き換え、同じGoogleアカウントのバックアップのみ受け付けます。復元操作はクラウド上のデータを変更しません。別端末への手動移行にもバックアップファイルを利用できます。バックアップファイルには個人情報や共有リンクの管理情報が含まれるため、安全に保管してください。

## 地図・経路検索

- 訪問先の座標を使って、車の道路ルートまたは徒歩ルートを表示できます。
- 外部経路サービスへの座標送信は初期状態でオフです。利用者がチェックを入れた場合に限り、選択中の旅行の訪問先座標をFOSSGISの経路検索サービスへ送信します。現在地のGPS情報は取得しません。
- 経路検索リクエストは外部サービスのサーバーログに記録される場合があります。外部送信を許可しない場合や経路を取得できない場合は、訪問順を示す概略線を表示します。概略線は実際の道路・徒歩経路ではありません。
- 公開経路サービスは利用制限のある共有サービスであり、応答や継続利用を保証するものではありません。大量・高頻度の利用は行いません。

## アカウント削除

- マイページから旅ログのアカウントとクラウド保存データを削除できます。実行には「DELETE」の入力と最終確認が必要です。
- 削除対象は旅行、日記、写真のクラウドコピー、支出、関連するSNSデータ、ログインセッション、現在の端末にある当該アカウントのローカルデータです。
- Googleアカウント自体は削除されません。ゲスト用データや別端末に残る未ログイン時のデータは対象外です。
- owner tracking導入前に発行した共有リンクは、発行時の無効化キーが保存されている端末からの無効化が必要な場合があります。
- 本番Workerのmigration 0011、所有者スキーマ、アカウント削除SQLのローカルD1分離テストは成功済み。実ユーザーによる削除操作は未実施です。

## 共有機能の制限

- 共有URLを発行した場合に限り、選択した旅行名、エリア、説明、訪問先、日記テキスト等が共有されます。
- 共有URLは原則として発行から365日で期限切れになります。
- 共有URLを知っている人は内容を閲覧できます。個人情報や現在地などを含めないでください。
- 共有ページには写真・動画本体は含まれません。写真のクラウド保存領域は非公開で、共有ページには公開されません。
- 動画のクラウド保存は未実装です。
- 共有URLの発行APIには、本文サイズ上限とIPハッシュ単位の回数制限があります。

## 技術構成

- Frontend: Cloudflare Pages（`tabi-log.pages.dev`）
- API: Cloudflare Workers（`tabi-log.haruto-9519.workers.dev`）
- Database: Cloudflare D1（`tabi-log-db`）
- 地図表示: Leaflet / OpenStreetMap
- 認証: Google Identity Services + Worker側IDトークン検証

## 公開後・継続開発で必要な確認

1. Googleログイン、ログアウト、セッション期限切れの実機確認
2. 旅行・日程・日記・支出の保存、再読み込み、再ログイン後の復元確認
3. 別アカウントから他人の非公開データを取得・変更できないことの確認
4. 写真の端末保存・クラウド同期・別端末取得・差し替え・削除の実機確認
5. 写真のバックアップ保存・復元、復元後の写真表示と既存データ保護の実機確認
6. 共有URLの発行・閲覧・無効化と、共有対象データの確認
7. スマートフォンでの表示、入力、アクセシビリティの確認
8. データのエクスポート・アカウント削除手順の整備
9. SNS向けデモUIと実際に利用できる機能の表示を整理
10. 動画の保存・表示・共有方法の設計と実装

「画面にボタンがある」だけでは完成とせず、保存・再読み込み・再ログイン・権限・エラー時の動作まで確認できた機能だけを完了扱いにします。

## 旅行の整理・共有に関する補足

- 旅行はキーワード検索、日付順／名前順の並び替え、アーカイブ／復帰、複製に対応します。アーカイブ状態はログイン時にD1へ同期します。
- 日別予定は手動で順序を入れ替えられます。順序はログイン時にD1へ同期します。
- 共有リンクの発行前に共有範囲を確認します。共有ページの地図座標は粗い位置に丸め、写真・非公開の日記・正確な位置情報は共有データに含めません。
- 旅行の検索、アーカイブ、復帰、複製、順序変更、共有・無効化は、公開サイトで実際に確認する必要があります。
